# klosetk.github.io

Personal portfolio site, served with GitHub Pages at **https://klosetk.github.io**.

Self-contained `index.html` (light and dark mode, no build step). Fonts load from Google Fonts and fall back to system fonts offline.

Project pages: [`brick-and-saddle-loft/`](brick-and-saddle-loft), an interior concept lookbook with a hover-to-shop overlay.

Architecture write-ups for the projects are in [it-automation-portfolio](https://github.com/klosetk/it-automation-portfolio).
